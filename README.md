# Unofficial Facepunch Sandbox Gamemode Docs

**Documentation** - https://notrabbi32.github.io/sandbox-mode-docs/

## What is this
An open source website documenting facepunches Sandbox Gamemode for an easier time making addons, maps, and content.   
Using visual-aids, descriptions, code snippets, and videos to break down and understand the inner workings of the game.

## Why was this made
Facepunch is spending most of their time improving the engine for developers. So, understandably not alot of time is spent making learning material for newer devs. 

Therefore, getting into making content for their sandbox mode is quite difficult having to spend most the time messing around with code, scouring the repo for information, and reading old threads that might be out of date. So here you go a simple documentation site to help people understand the backend.

## Contributing
This was made to be a learning/helping tool anyone can contribute via pull requests. **You will be properly credited!** I am very open to corrections and fixes. I want S&box to succeded and only us devs can make it happen!

Pages are simple `.md/mdx` files stored in `/docs` or `/blog` folder. Anyone can contribute to the blog for notifying of update/future changes tot he game. Follow formatting styles of other pages, and when contributing to blogs add yourself as an author in `/blog/authors.yml` with your information if you want.
